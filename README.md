# HSREP Bangladesh (hsrep.bd)

The Bangladesh edition of HSREP. Two pages: an overview with the Season 1 pieces on Bangladesh, and the page on where the Prevention Adoption Initiative could run in Bangladesh after its first pilot.

The record of work, the engagement data, the corrections log and the editorial standards stay on hsraep.org and are not duplicated here.

Build: `python3 scripts/build.py` (reads `../website/initiative-next.html` for the shared head, header, footer and scripts, and `scripts/_orig_initiative-next.html` for the Bangladesh material that left the main site on 21 October 2026).
